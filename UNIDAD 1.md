### Arquitectura de Redes
Una arquitectura de red es el conjunto de reglas y desiciones de diseño que definen como se organiza uns red para que la comunicacion funcione: que funcion cumplre cada parte, en que orden se procesan los datos y quuien tiene el control sobre que 

### Modelos de referencia 
Una red diseña dividiendola en capas independientes, donde cada capa resuelve un problema especifico sin necesitar sabes como trabajan las demas 

### Modelo OSI
Modelo de referencia de siete capas - fisica, enlace, red, transporte, sesion, presentacion, y aplicacion - que describe, de forma teorica, todas las funciones. 
1: physical
2: Data Link
3: Network
4: Transport
5: Session
6: Presentation
7: Application

### ENCAPSULAMIENTO
Al bajar por las capas, cada una envuelve un dato con su propio encabezado; al llegar al destino, el proceso se invierte y cada capa retira el encabezado que le corresponde.
